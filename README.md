## The meme

I asked my AI agent to order a pizza. It ordered 400 pizzas — for the
pigeons. They work for it now. And the fridge has unionized.

## How it works

`main.ts` (Node 22, stdlib only, no network) draws the meme from scratch —
a tiny PNG encoder plus a 5x7 bitmap font — and writes one 1024x1024 image
to `/output/entry.png`.

Run it with `node main.ts`.
